会长的发布指南

第一次使用时，请先接受管理员发来的 GitHub 协作邀请。之后只需要收藏发布台地址，用自己的 GitHub 账号登录。

发布一条新内容

  1. 进入发布后台，选择“活动与交流”“协会法会”“主要成员”或“国际联谊”。商品请查看下方的商品上架指南。
  2. 点击“新增”，填写中文标题和介绍。正文空一行即可分段；不需要输入代码。
  3. 在“图片与视频”中添加素材，填写简短说明。视频可添加封面。建议先压缩图片；单个文件最多20MB。
  4. 填写中文后，点击英文标题上方的“一键补齐英文”。系统只翻译缺失的英文字段，保留已有英文；请检查人名、职务与日期，再保存发布。没有英文时，英文页面仍会显示中文。需要出现在首页的活动，打开“在首页展示”。
  5. 查看右侧预览，可切换中英文。检查姓名、日期、地址、照片是否正确。
  6. 先保存草稿。确认无误后，使用“发布”菜单发布；如要求状态流转，依次选择“审核中”“准备就绪”，再发布。无需等待其他人批准。
  7. 发布请求提交后，等待网站更新，再打开官网核对。编辑器预览不代表网站已更新成功。

上架一件商品

  1. 选择“在线商店”，新增商品，填写名称、类别和真实商品介绍。商品网址会自动生成，已有商品继续使用原来的网址，无需手动填写。把已确认的图案、材质、尺寸等写在“中文商品细节”，每行一项；没有确认的信息可以不填。
  2. 在“商品图片”里上传真实照片，第一张作为商品主图。图片说明可以留空，系统会自动补充基础说明；如需说明正反面或特写，可填写更具体的中英文说明。其他角度、细节照片可继续添加。
  3. 需要帮助写文案时，点击名称下方的“草拟商品文案”。AI 会根据已填写的信息草拟中英文介绍、细节和常见问题。逐项检查和编辑，勾选要使用的字段，点击“应用选中文案”。已有内容默认不会替换；可自行勾选替换。生成期间改动商品内容后，请重新生成，以免使用旧资料。
  4. 需要展示图时，展开“制作商品展示图”，选择一张不超过6MB的 JPG、PNG 或 WebP 商品原图，按需填写画面要求。图片将发送给 AI 服务生成参考图。仔细核对雕刻、符字、材质表现、形状和颜色，确认后下载，再通过“商品图片”上传，并打开“AI 辅助图片”。不符合实物的图片请勿使用。
  5. 填入与商品对应的 Stripe 收款链接、美元售价和销售状态。打开收款链接核对名称、单件价格与款式，然后勾选“已核对收款商品与价格”。只有“有货，可购买”、库存不为0、售价有效、链接已核对的商品才显示付款按钮。没有收款链接或价格待定时，选择“咨询购买”；切勿借用其他商品的收款链接。
  6. 预览中英文页面，检查商品事实、图片和常见问题。确认后打开“在网站上显示”，保存并发布。发布后会自动生成中英文商品详情页及搜索、分享信息。

SEO/GEO 自动完成：只需维护商品名称、介绍、规格、照片和收款信息。系统会自动更新搜索标题、摘要、购买问答和商品索引，不需要填写关键词或技术设置，不需要额外点击 AI 按钮，也不消耗 AI 额度。以后修改商品资料，相关信息会随发布一起更新。常见问题可选填文化、图案或用途说明；价格、库存、购买与配送信息由对应设置自动生成，不必重复填写。未确认的规格和承诺请留空。

AI 文案和展示图都是草稿，不会自动上架。商品价格、库存、邮寄范围及退换安排需要人工核对；传统寓意不应写成健康、财运或考试结果的保证。搜索引擎和 AI 搜索是否收录由各平台决定。

如提示“AI 服务尚未启用”，管理员需要先部署商品 AI 服务并设置服务密钥。你仍可手动编辑、上传照片和发布商品。本机预览不调用正式 AI 服务。

管理款式与库存

  1. 同一商品有多个图案或形制时，在“商品款式”中逐款添加。填写独立标识、中英文名称，可上传对应实物图并填写图片说明。共同规格写在商品细节中，差异写在每款的细节中。
  2. 每款设置自己的售价、销售状态与库存数量，再填写独立的 Stripe 收款链接。Stripe 订单的商品名称必须清楚标识所购款式，避免发货时无法辨认。打开收款页核对后勾选“已核对此款式和收款金额”。款式之间不能共用同一收款链接。
  3. 打开“在商品页展示此款式”才会展示。设置了任何款式后，商品原来的统一收款入口停用；不完整的款式不会借用商品统一链接。没有确认价格或供货的款式可设为“咨询购买”。
  4. 库存留空表示未录入数量，0 会暂停网站付款入口；售罄也可选择“暂时缺货”。这里的数量需要人工更新，付款后不会自动扣减，网站售价也不会自动同步到 Stripe。收到订单后，请及时更新库存并发布；如需限制付款数量，同时在 Stripe 中更新或停用对应链接。
  5. 保存并发布后，检查中英文商品页上的款式、照片和付款入口。后台预览中的付款按钮不可用于真实支付。

维护配送、退换与客服联系

在后台选择“商店设置”，打开“配送、退换与客服联系”。这里的资料统一显示在商店、商品页面及“配送与退换”页面。

  • 公开客服：填写对外客服邮箱和联系说明。订单通知收件人、退款和订单处理仍在 Stripe 后台设置；不要在此填私人邮箱、账户信息或服务密钥。
  • 配送：填写发货地点、配送范围、运费规则、备货与发货时间、预计运输时间、物流追踪和自取安排。
  • 售后：填写退货退款、取消订单、损坏错发或丢件、定制商品的处理规则，以及已确认的税费与关税说明。
  • 中英文：两种语言分别填写；英文缺失时显示中文。没有确认的信息请留空，页面不会补出承诺。这里是准备公开的商店规则，不用于记录客户订单或收货地址。

查看预览后保存并发布。商品规格、库存和商店规则可以随时修改，网站会在发布后更新；付款地址、运费和税费等 Stripe 设置仍需在 Stripe 后台同步核对。

付款与发货

商品付款由 Stripe 托管。使用 Stripe 后台查看订单、退款及收款提醒，并按订单记录的具体款式安排发货。商店后台不保存银行卡资料或客户收货信息，也不提供自动扣库存或自动发货。正式接单前，请让网站管理员使用 Stripe 测试模式核对款式、地址、金额、成功、失败和取消付款流程。

修改、排序与下架

打开对应栏目中的现有条目即可修改。“显示顺序”数字越小越靠前。成员可依次设为10、20、30。

想撤下某条内容，关闭“在网站上显示”，保存并发布即可。恢复时重新打开，再发布。后台不提供直接删除，以免误删资料。

草稿和资料的边界

保存草稿不会更新官网；关闭编辑器前请先保存。网站仓库目前公开，草稿分支和上传素材也可能被他人查看。这里仅存放准备公开的协会资料，请勿上传个人证件、私人联系方式或未获许可公开的资料。

常见问题

登录被拒绝：确认使用获邀请的 GitHub 账号，并已接受协作邀请。如有额外登录验证，请按 GitHub 提示操作。

图片没有出现：确认文件上传完成，并填写素材说明。可使用 JPG、PNG、WebP 或 GIF。视频使用 MP4 或 WebM。

发布后官网没变化：网站生成需要时间。稍后刷新；若仍未更新，请联系管理员查看发布状态，不要反复点击发布。

保存提示冲突：可能有人同时修改了同一条内容。先把未保存文字复制到自己的文档，再重新打开条目核对后保存。

本机预览：带“本机编辑预览”提示的页面仅供测试，保存不会更新官网，不会要求 GitHub 登录。
