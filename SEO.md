# Search and sharing metadata

Production pages are generated by `scripts/build.mjs`; `scripts/seo.mjs` owns titles, descriptions, canonicals, language alternates, social cards and structured data. Edit its page metadata when a section's purpose changes.

Each public page has a Chinese URL at the root and an English URL under `/en/`. The build renders the selected language and shared navigation before JavaScript runs. Language switching navigates between paired URLs and preserves the section fragment. Existing Chinese URLs remain unchanged. Missing entry translations keep the existing Chinese fallback.

The sitemap is generated from the same page list and contains both languages. It omits `lastmod` rather than publishing inaccurate dates. Organization data uses public association information; it does not invent ratings, honors or a street address. Admin pages retain their existing `noindex` directives.

Verification: `npm test` and `npm run build`. Check `/en/about.html`, language switching, and `/sitemap.xml` after deployment. In Google Search Console, submit `https://yangzhu.org/sitemap.xml` and inspect the home page and `/en/`. Account ownership verification requires the site's verified owner; deployment alone does not submit a Search Console request or guarantee indexing or ranking.
